# Global Shipment Analytics - Power BI Project

### 📥 Download
PBIX file (507KB) is in this repo - Click on `powerbi.pbix` > Download

### 📊 Overview
8-page end-to-end Power BI dashboard for global chocolate company shipment analysis.

### 🎯 KPIs
- Total Boxes Shipped: 8831K
- Total Amount: 141.49M
- Total Profit: 81.10M
- Total Profit %: 57.32%

### 📈 Key Insights
- **Geo:** India 40.41M (28.56%) top, UK/Canada 10M lowest
- **Product:** Organic Choco Syrup 11.9M top seller, Peanut Butter Cubes 90.26% most profitable
- **Delivery:** Delivered 21.22K, Shipped 2.17K, Placed 0.47K
- **Team:** Jucies 25.73% top, Delish 30.21% share
- **Trend:** Shipments grew 485 to 1440 (Peak Dec 2024)
- **Salesperson:** Ponnan Delhi 68.96L profit highest

### 📑 Pages
Page 1: Amount by Product & Team | Page 2: Profit by Geo | Page 5: Profit by Salesperson & Month | Page 6: Amount vs Last Year + Geo | Page 7: Amount by Product | Page 8: Global Overview + Map

### 🛠️ Tech Stack
Power BI Desktop | Power Query | DAX (Profit %, TA 12, Total Amount) | Data Modeling
